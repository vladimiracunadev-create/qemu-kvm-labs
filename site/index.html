PRIMERO, EL MODELO MENTAL

QEMU construye el ordenador. KVM acelera su CPU. Libvirt lo administra.

Una máquina virtual es un ordenador definido por software: recibe CPU, memoria, disco, red y firmware propios, y arranca su propio sistema operativo. Este repositorio te deja ver y controlar cada capa.

Fue creado para cubrir el espacio entre instalar un paquete y comprender una plataforma de virtualización. Cada concepto produce un recurso real y evidencia consultada desde el host o el guest.

PREGUNTAS CLAVE

Antes de ejecutar.

¿Necesito Linux?

Los labs completos usan KVM y requieren Linux. En Windows la ruta es WSL2 cuando expone /dev/kvm. macOS puede ejecutar los labs de discos y arranque con TCG.

¿Esto crea contenedores?

Crea máquinas virtuales con su propio kernel. Los contenedores comparten el kernel del host.

¿Necesito una cuenta cloud?

No. El recorrido principal es local. La migración necesita un segundo host que tú controles.

¿Cómo sé que funcionó?

Las verificaciones consultan qemu-img, libvirt, el guest agent y SSH. La evidencia queda en archivos locales; no depende de mensajes de éxito prefabricados.
