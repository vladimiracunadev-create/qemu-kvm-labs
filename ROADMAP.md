# Roadmap

## v1.0.0

- Doce laboratorios progresivos y verificables.
- vm-manager para crear, listar, arrancar, detener, clonar, snapshotear y eliminar VMs.
- CI para código, scripts, XML, catálogo y documentación.
- Sitio de catálogo en GitHub Pages.

## Futuro

- Pools de almacenamiento configurables.
- Snapshots externos coordinados con guest agent.
- Backend opcional libvirt-python.
- Métricas de rendimiento reproducibles entre hosts.
- Laboratorio de migración con almacenamiento compartido NFS.
