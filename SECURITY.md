# Seguridad

Reporta vulnerabilidades de forma privada mediante GitHub Security Advisories del repositorio.

Los laboratorios modifican virtualización, redes y almacenamiento locales. Revisa el nombre de la VM y la URI libvirt antes de ejecutar. El lab 11 rechaza dominios que no comienzan por lab-. No ejecutes ejercicios contra infraestructura que no controles.

No guardes claves privadas, tokens, contraseñas, seeds generadas ni imágenes de VM en Git. La configuración cloud-init contiene únicamente un marcador para una clave pública.
